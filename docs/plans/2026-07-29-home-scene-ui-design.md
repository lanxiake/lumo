## 1. 设计目标

| 目标 | 说明 |
|------|------|
| **一眼能玩** | 3–8 岁无需读长文，靠图标 + 动画 + 语音引导知道点哪里 |
| **多宠一致** | caneko / klee / gengar 共用同一套场景热点与逻辑，仅调锚点/缩放/翻转 |
| **养+学同屏** | 喂食、学习、对话、主线提示都在主界面完成，少跳页 |
| **反馈够甜** | 每次有效操作都有动画 + 轻音效 + 短句，避免「点了没反应」 |
| **可扩展** | 物品、热点、特效用 JSON 描述，Phase 2 加家具不改核心代码 |

## 2. 画面分层与坐标系

### 2.1 渲染层级（自底向上）

```
Z0  SceneBackdrop      房间底图 + 静态装饰（不可点）
Z1  SceneAmbient       环境微动（窗帘飘、窗外云）— MVP 可用 CSS/轻 RN 动画
Z2  SceneItems         可交互物品精灵层（食盆、书桌…带热点）
Z3  PetStage           WebView：Shimeji 精灵（透明底）
Z4  PetEffects         粒子/爱心/星星（RN 绝对定位，pointerEvents:none）
Z5  SpeechLayer        对话气泡、主线气泡、表情 emoji 浮层
Z6  QuestGuide         主线顶栏、手指提示、物品高亮光圈
Z7  HUD                数值条、选宠、设置
Z8  InputBar           语音/文字输入（复用现有）
Z9  Modal              Playground / 设置 / 权限弹窗
```

**原则**：宠物在 Z3，热点在 Z2；**热点不依赖宠物 hitTest** 做喂食/书桌（避免三宠体型差导致点不到）。点宠物本体单独处理「轻拍 / 对话 / intro」。

### 2.2 坐标系

- 全屏使用 **归一化坐标** `0..1`（left/top 为视口百分比），与现有 `SceneBackground` 一致，横竖屏旋转时热点随 `%` 重排。  
- 宠物 **舞台锚点** `petAnchor`：默认 `(0.5, 0.72)`（脚贴地线）。  
- **地面线** `groundY = 0.78`：宠物 idle 脚底对齐此线；WALK 沿 `[0.15, 0.85]` 水平区间。

### 2.3 主界面线框（竖屏）

```
┌──────────────────────────────────────┐  ← safe area top
│ [主线条]  见面/喂食/学习…    [宠][⚙] │  Z7  高 56dp
│ 饿 ●●○○  心情 ♥♥♥  Lv.2              │
├──────────────────────────────────────┤
│  🪟窗户   ☁️                          │  Z0–Z1
│                                      │
│     🛏️床        📚书桌+台灯          │  Z2 物品
│                                      │
│          ┌─────────┐                 │
│          │  精灵宠  │  ← Z3          │
│          └─────────┘                 │
│   🥣食盆    🧸玩具    🌱盆栽          │
│════════════════地面线════════════════│  groundY
├──────────────────────────────────────┤
│ 「先吃一点再学习吧～」  ← Z5 气泡      │
├──────────────────────────────────────┤
│ [🎤按住说] [输入…]  [📱放到桌面]      │  Z8
└──────────────────────────────────────┘
```

## 3. 场景「温馨小屋」空间设计

### 3.1 空间分区

| 分区 | 视觉 | 功能 |
|------|------|------|
| **天空/窗外** | 窗户、云、阳光 | 环境叙事；点窗户播 GREET + 短句（非主线） |
| **后墙** | 墙纸、书架、挂画 | 书桌靠后墙；书架 MVP 仅装饰 |
| **活动区** | 地毯、中央空地 | 宠物 idle / walk / 点击互动 |
| **左侧休息区** | 床、枕头 | P1 睡觉；MVP 点床 SIT + 「想睡一会儿」 |
| **右侧学习区** | 书桌、台灯、书本 | **主线学习**入口 |
| **前方地面** | 食盆、玩具 | **主线喂食**、玩耍加心情 |

### 3.2 视觉风格（冻结方向）

- **温暖卡通风**：偏儿童绘本，非写实 3D。  
- 主色：米黄墙 `#FFF4E6`、木地板 `#E8C49A`、软粉点缀 `#FFB8C6`。  
- MVP 可 **底图 + 分区色块 + emoji/简单矢量物品** 实现；正式版换一张 `cozy_home_bg.png`（约 1080×1920）。

### 3.3 静态装饰（不可交互，Z0）

| 元素 | 位置 % | 说明 |
|------|--------|------|
| 墙纸纹理 | 全屏 | 浅条纹或波点 |
| 窗户 | left 72, top 8 | 带栏杆，窗外蓝天 |
| 挂画 | left 8, top 22 | 星星画，儿童房感 |
| 书架 | left 4, top 38 | 摆书，不可点 |
| 地毯 | left 25, top 70, w40% | 椭圆暖色地毯 |
| 踢脚线 | bottom 22% | 区分墙与地板 |

### 3.4 环境微动（Z1，MVP 可选 1～2 个）

| 元素 | 动画 | 周期 |
|------|------|------|
| 窗帘 | 左右轻摆 3px | 3s loop |
| 窗外云 | 缓慢平移 | 20s loop |
| 台灯 | 学习步骤时 glow 脉冲 | 与 QuestGuide 联动 |

## 5. 多宠物样式兼容

Shimeji 三宠 **体型、比例、语义** 不同，场景用 **统一逻辑 + 每宠布局覆盖** 兼容。

### 5.1 宠物分类与差异

| petId | 类别 | 视觉特征 | 兼容要点 |
|-------|------|----------|----------|
| `shimeji_caneko` | 四足猫 | 矮、宽、四脚 | 锚点偏低；hitBox 偏宽 |
| `klee` | 人类幼童 | 中高、双足 | 标准锚点；GREET 仅 4 帧 |
| `gengar_shimeji` | 异型浮游 | 中高、无明确脚 | 锚点略上浮 -4% Y；可略放大 |

### 5.2 每宠布局覆盖（`petLayoutOverrides`）

```json
{
  "shimeji_caneko": {
    "scale": 1.0,
    "anchor": { "x": 0.5, "y": 0.74 },
    "hitBox": { "left": 0.38, "top": 0.58, "width": 0.24, "height": 0.20 },
    "facingDefault": "right",
    "walkSpeed": 0.08
  },
  "klee": {
    "scale": 1.05,
    "anchor": { "x": 0.5, "y": 0.72 },
    "hitBox": { "left": 0.40, "top": 0.56, "width": 0.20, "height": 0.24 },
    "facingDefault": "right",
    "walkSpeed": 0.10
  },
  "gengar_shimeji": {
    "scale": 1.15,
    "anchor": { "x": 0.5, "y": 0.68 },
    "hitBox": { "left": 0.36, "top": 0.52, "width": 0.28, "height": 0.26 },
    "facingDefault": "right",
    "walkSpeed": 0.09
  }
}
```

- **scale**：相对 128dp 舞台宽度的缩放；异型略大增强存在感。  
- **anchor**：精灵脚底对齐 `groundY` 的归一化点。  
- **hitBox**：仅用于点「伙伴」；与物品热点分离。  
- **facingDefault**：Shimeji 原图面向右；向左走 `flipH=true`。

### 5.3 动画映射（三宠共用表，config 行号不同由 registry 解决）

| 逻辑动作 | Shimeji 状态 | 三宠是否一致 |
|----------|--------------|--------------|
| 待机 | STAND | ✓ |
| 走路 | WALK | ✓ |
| 思考/学习坐 | SIT | ✓ |
| 打招呼/开心/喂食反馈 | GREET | ✓（klee GREET 4 帧） |
| 无独立「吃饭」行 | GREET 代替 | ✓ |

**无独立表情贴图**：情绪靠 §8 气泡 emoji + 粒子 + 数值 HUD，不靠换脸纹理。

### 5.4 换宠时的场景行为

1. 保存当前 `petX`（归一化位置）。  
2. 加载新 sheet + override。  
3. 若新宠 anchor 不同，**微调 Y** 使脚仍贴地线。  
4. 播放 STAND 0.5s，气泡：「我是{name}！」  
5. 不重置主线/Care（同一只「伙伴」换皮，或视为同一伙伴的不同样子——**产品文案采用后者**，避免孩子困惑）。

## 6. 宠物运动规则

### 6.1 运动模式枚举

| 模式 | 触发 | 动画 | 位移 |
|------|------|------|------|
| `IDLE` | 默认 | STAND | 无 |
| `WALK` | 定时闲逛 / 被引导走向物品 | WALK | 水平匀速 |
| `APPROACH` | 点食盆/书桌且距离>阈值 | WALK | 走向物品锚点 |
| `INTERACT` | 到达物品或立即交互 | GREET/SIT | 停止位移 |
| `DRAG` | 长按宠物（P1） | DRAG 或跟随手指 | 跟手 |
| `LOCKED` | Playground/全屏弹层打开 | STAND/SIT | 冻结 |

### 6.2 闲逛（Ambient Walk）

- **条件**：`quest.completed` 或 `step` 非 intro；无输入 8s；非 LOCKED。  
- **行为**：随机目标 `x ∈ [0.2, 0.8]`，WALK 过去，到达 STAND，停 3～6s 再随机。  
- **边界**：`petX` 钳制在 `[0.12, 0.88]`，触边翻转 facing。  
- **频率**：每轮闲逛 1～2 次后长待机，避免一直乱跑干扰点击。

### 6.3 引导走向（Quest Approach）

- `first_feed` 高亮食盆时：若宠物距食盆中心 >15% 宽，先 `APPROACH` 到 `(0.18, groundY)`，再允许 FEED 动画。  
- `first_study` 同理走向书桌 `(0.78, 0.65)`。  
- 孩子也可 **直接点物品**，不必等走近（**冻结：点物品立即交互**，走近仅作自动演示 1 次）。

### 6.4 竖屏专属

- 宠物活动范围：**地毯区域**内，不走上床/书桌台面（Y 锁定在 groundY）。  
- 横屏（若支持）：groundY 调整为 0.82，热点坐标用同一套 % 自动适配。

### 6.5 与悬浮形态对比

| 能力 | 家园 | 悬浮 |
|------|------|------|
| 垂直运动 | 仅 ground 线 | 全屏（Phase 2 物理） |
| 爬墙/倒挂 | ✗ | Phase 2 |
| 闲逛 WALK | ✓ 水平 | ✓ 水平 |

## 7. 交互规则总表

### 7.1 输入手势

| 手势 | 目标 | 行为 |
|------|------|------|
| 单击 | 伙伴 hitBox | 见 §7.2 |
| 单击 | 场景物品 | 见 §4 |
| 长按 | 伙伴 | P1：拖拽位置（MVP 不做） |
| 双击 | 伙伴 | 打开文字输入聚焦（可选） |

**儿童友好**：单击即反馈，无「长按 500ms 才生效」的主线操作。

### 7.2 点击伙伴

| 主线 step | 行为 |
|-----------|------|
| `intro` | `START` → first_feed；GREET + 气泡「我们一起玩吧！」 |
| `first_feed` | GREET + 「我饿了～」 |
| `first_study` | GREET + 「我们去学习吧！」 |
| `completed` | GREET + 打开/聚焦对话（不强制全屏聊天） |

### 7.3 点击食盆 `item_bowl`

| 条件 | 结果 |
|------|------|
| `step=first_feed` 且 `!hasFedOnce`（主线门闩触发） | `FEED` + `FEED_OK` + GREET + 特效 §9.1 |
| hunger ≤ 20（很饱） | GREET + 「我已经不饿啦」+ 碗旁 ✨ 小闪（不改变数值） |
| 否则 | `FEED` + GREET + 特效 §9.1（若 `step=first_feed` 且未完成再追加 `FEED_OK`） |
| 冷却 | MVP 无 |

### 7.4 点击书桌 `item_desk`

| 条件 | 结果 |
|------|------|
| `!hasFedOnce` | **拦截**：气泡「先吃一点再学习吧～」+ 食盆 highlight 脉冲 2s（气泡带「知道了」可关闭） |
| 已喂食 | 台灯亮 → 打开 `mainline_count_v1` Playground |
| `completed` 后 | 同左，自由练习 |

### 7.5 点击其他物品（P1）

见 §4.2；统一：`GREET` + 短气泡 + 可选微量 mood。

### 7.6 并发与锁

- Playground 打开 → 宠物 `LOCKED` + SIT。  
- 权限弹窗 / 设置全屏 → LOCKED。  
- 喂食动画播放中（GREET 非 loop，约 1s）→ 忽略重复点食盆。

## 8. 文字与表情展示

Shimeji **无 Live2D 式表情索引**，采用 **四层表达**：

### 8.1 层次模型

```
[HUD 数值]     饿/心情/等级 — 持续可见
[状态 emoji]   宠物头顶小图标 — 饥饿😋、开心♥ 等
[对话气泡]     短句台词 — 主线/点击/Agent 回复摘要
[精灵动画]     STAND/WALK/SIT/GREET — 身体动作
[粒子特效]     爱心/星星/食物 — 短时反馈
```

### 8.2 对话气泡（SpeechLayer）

| 类型 | 样式 | 最大字数 | 时长 |
|------|------|----------|------|
| `quest` | 顶栏下或宠物上方圆角白底 + 粉边 | 24 字 | 直至 step 变 |
| `pet` | 宠物右上云朵气泡 | 18 字 | 3s 淡出 |
| `system` | 底部 toast | 16 字 | 2s |
| `agent` | 复用现有聊天流；家园可显示**最后一句摘要**在气泡 | 单行 20 字 | 说话结束后 5s |

**字体**：圆润无衬线，≥16sp，深色字 `#4A3728`。

**气泡展示规则（MVP 固定）**：同一时刻最多显示 **1 个** speech bubble；当新事件需要气泡时，直接替换旧气泡而不是叠加。`quest/blocked` 气泡提供「知道了」按钮；`pet/system/agent` 气泡默认自动淡出。

**示例**：

- quest：`「去点那个小食盆吧～」`  
- pet：`「好吃好吃！」`  
- blocked：`「先吃一点再学习吧～」（知道了）`

### 8.3 头顶状态 emoji（PetStatusBadge）

| 条件 | emoji | 位置 |
|------|-------|------|
| hunger > 70 | 🍖 | 宠物头顶右 |
| mood ≥ 80 | ✨ | 宠物头顶左 |
| mood < 30 | 💧 | 头顶左 |
| speaking | 💬 | 头顶（对话中） |
| thinking | … 动画 | 头顶 |

最多同时 **2 个** badge，避免杂乱。

**MVP 前台时间衰减**（非离线）：App 前台运行时 `hunger` 会缓慢上升、`mood` 会轻微下降，因此在一段时间后会出现 🍖/✨/💧 等 badge 与相应“想要/不舒服”的气泡提示。

### 8.4 表情与对话态映射

| petStateMachine | 精灵动画 | 气泡/ badge |
|-----------------|----------|---------------|
| idle | STAND | — |
| listening | SIT | 💬「我在听…」 |
| thinking | SIT | … |
| speaking | GREET 慢循环或 STAND | 流式摘要 |
| safety_blocked | SIT | 系统 toast |

### 8.5 三宠台词差异（同一逻辑，文案可带 petName）

```ts
const feedLines: Record<PetId, string[]> = {
  shimeji_caneko: ["喵～好吃！", "还要还要！"],
  klee: ["哇！好吃！", "谢谢主人！"],
  gengar_shimeji: ["嘿嘿～", "好香呀！"],
};
// 随机一条，增强角色感
```

## 9. 交互动画与特效

### 9.1 喂食 `FEED`

| 阶段 | 时长 | 表现 |
|------|------|------|
| 预反馈 | 0ms | 食盆缩放 1.0→1.1→1.0 |
| 宠物 | 0–900ms | GREET（或 SIT 嚼，MVP GREET） |
| 粒子 | 200–800ms | 3～5 个 🍖/⭐ 从碗飞向宠物 |
| 数值 | 300ms | HUD 饿条减少，数字弹跳 |
| 音效 | 0ms | `app_play_sound` 清脆「叮」 |

### 9.2 学习开始（开书桌）

| 表现 |
|------|
| 台灯 glow 放大 1.2 + 暖黄光圈 |
